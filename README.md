# PS5 Relapse для OpenWrt

Локальный сервер для запуска Relapse Exploit на PS5 через браузер руководства пользователя. Проект устанавливается на роутер OpenWrt одной командой и раздаёт страницу консоли.

## Быстрый запуск

Для установки выполните в SSH-сеансе OpenWrt от root:

    (set -eu; t=$(mktemp -d); trap 'rm -rf "$t"' 0; wget -T 30 -O "$t/install.sh" https://raw.githubusercontent.com/ant-m13/ps5-relapse-openwrt/main/install.sh; sh "$t/install.sh")

Быстрый запуск скачивает проект, проверяет OpenWrt и архив, предлагает выбрать PS5, сохраняет её параметры, устанавливает недостающие пакеты, копирует сайт в `/srv/ps5`, создаёт локальный DNS, HTTPS-сертификат и токен управления нагрузками. После подтверждения он включает веб-сервер, перенаправления DNS/HTTP/HTTPS и блокировку внешнего трафика выбранной PS5, затем проверяет службы. Если у PS5 уже есть DHCP-имя и закреплённый IP, они используются без изменений. Перезагрузка роутера не требуется.

Для загрузки проекта роутеру нужны доступ в интернет, правильное системное время, сертификаты CA и `wget` с HTTPS.

Если проект уже скопирован на роутер:

    sh install.sh

Проект рассчитан на OpenWrt с opkg или apk, firewall4 и dnsmasq. Роутер должен быть шлюзом PS5 и видеть её MAC-адрес; точка доступа между ними должна работать мостом. Установщик настроит локальный DNS, веб-сервер и HTTPS.

## Использование

После установки подключите PS5 к Wi-Fi, оставьте получение IP автоматическим, укажите LAN-адрес роутера как DNS и откройте руководство пользователя PS5. Команды `sh install.sh offline` и `sh install.sh online` включают и отключают блокировку доступа PS5 в интернет. Команда `sh install.sh inspect` показывает состояние и проверяет службы.

Дополнительные ELF-файлы пользователь копирует на роутер вручную в /srv/ps5/payloads/optional/. На странице PS5 откройте «Дополнительные нагрузки», нажмите «Обновить список» и отметьте нужные файлы. Кнопка запуска отправляет отмеченные файлы на PS5 после Relapse. Кнопка сохранения записывает список и его порядок для автозапуска после следующих запусков.

Список автозапуска можно настроить также в /srv/ps5/payloads/optional/manifest.json. Каждый ELF должен находиться в этой же папке. Чтобы отключить автозагрузку, оставьте пустой массив [].

## Порядок работы и меню

После установки запустите `sh install.sh menu`.

1. **Установить сервер / применить настройку** — установка с нуля или применение подготовленных файлов.
2. **Обновить проект из GitHub** — скачивание актуального проекта с сохранением настроек роутера.
3. **Установить недостающие пакеты и обновить сайт** — устанавливает только отсутствующие пакеты и обновляет файлы сайта без включения правил firewall.
4. **Состояние и проверка служб** — объединённый вывод состояния, диагностики и проверка DNS, HTTPS и правил.
5. **Режим online — обычный интернет PS5** — отключение локального режима.
6. **Режим offline — локальный запуск Relapse** — включение перенаправлений и блокировки внешнего трафика.
7. **Восстановить настройку** — восстановление резервной копии.
8. **Удалить настройку** — удаление служб и правил мастера.
0. **Выход** — закрытие меню.

Обычный порядок: `configure` → `prepare` → `apply`. После применения подключите PS5 к Wi-Fi, оставьте автоматический IP, укажите LAN-адрес роутера как DNS и откройте руководство пользователя PS5. Перезагрузка роутера не требуется.

Те же действия доступны без меню: `sh install.sh configure` выбирает PS5 и сохраняет параметры; `sh install.sh update` обновляет проект из GitHub; `sh install.sh prepare` устанавливает пакеты и обновляет сайт; `sh install.sh apply` включает службы и правила; `sh install.sh inspect` показывает состояние и проверяет службы; `sh install.sh offline` включает локальный режим; `sh install.sh online` возвращает обычный интернет; `sh install.sh restore` восстанавливает резервную копию; `sh install.sh uninstall` удаляет настройку мастера. Старые команды `diagnose`, `status` и `check` также поддерживаются отдельно.

## Токен управления нагрузками

Токен хранится в `/etc/ps5-openwrt/payloads.token` и выводится командой `sh install.sh status`. По умолчанию он содержит 64 символа. Для ручного ввода можно задать собственный код длиной не менее 16 символов:

    printf '%s\n' 'PS5-relapse-2026' > /etc/ps5-openwrt/payloads.token
    chmod 600 /etc/ps5-openwrt/payloads.token

После смены токена обновите страницу сайта. Токен разрешает просмотр списка ELF, загрузку файлов и изменение автозапуска.

## Порядок запуска Relapse

1. Установите и примените сервер на роутере.
2. Включите локальный режим PS5 командой `sh install.sh offline` или через пункт меню **«Режим offline — локальный запуск Relapse»**. Этот режим блокирует внешний трафик выбранной консоли и перенаправляет необходимые запросы на локальный сервер.
3. На PS5 откройте руководство пользователя и запустите Relapse.
4. Дождитесь запуска ELF loader.
5. Запустите или отправьте выбранные нагрузки в разделе «Дополнительные нагрузки», например `pldmgr.elf`.
6. После завершения отправки нагрузок верните обычный интернет командой `sh install.sh online` или через пункт меню **«Режим online — обычный интернет PS5»**.
7. Переподключите PS5 к Wi-Fi, чтобы очистить DNS-кэш.

Переключение в режим `online` отключает локальные перенаправления и блокировку внешнего трафика. Уже запущенные нагрузки от этого не отменяются.

## Пошаговая инструкция

1. Подключитесь к роутеру по SSH от `root` и запустите `sh install.sh` или `sh install.sh menu`.
2. Выберите PS5 по MAC-адресу. Если для неё уже есть закреплённый IP и имя, мастер использует их автоматически.
3. В меню выполните пункт 1. Если сайт нужно обновить, сначала выполните пункт 3 «Установить недостающие пакеты и обновить сайт», затем снова пункт 1.
4. После завершения убедитесь, что выбран локальный режим (`sh install.sh offline` или пункт 6).
5. На PS5 оставьте автоматическое получение IP, подключитесь к Wi-Fi этого роутера и откройте приложение «Руководство пользователя». Должна открыться локальная страница PS5 Relapse.
6. Запустите Relapse и дождитесь сообщения о готовности ELF loader.
7. Откройте на странице раздел «Дополнительные нагрузки». Для доступа с компьютера введите токен из `sh install.sh status`; сама PS5 получает доступ без ручного ввода токена.
8. Чтобы добавить нагрузку, выберите ELF-файл в поле «Добавить ELF-файл» и нажмите «Загрузить на роутер». Ограничение размера — 8 МиБ. Файл также можно скопировать по SSH в `/srv/ps5/payloads/optional/`.
9. Отметьте загруженную нагрузку. Кнопка «Запустить» отправляет её на PS5, а «Сохранить автозапуск» записывает выбранные файлы и порядок в `manifest.json`.
10. После успешной отправки нагрузок включите обычный интернет через пункт 5 меню или команду `sh install.sh online`, затем переподключите PS5 к Wi-Fi.

## Быстрый запуск

Команда из раздела «Быстрый запуск» загружает проект в `/root/ps5-relapse-openwrt`, проверяет архив и OpenWrt, запускает выбор PS5, устанавливает недостающие пакеты, копирует сайт в `/srv/ps5`, создаёт DNS-службу, HTTPS-сертификат и токен, а затем после подтверждения включает веб-сервер и правила для выбранной консоли. Если DHCP-резервирование уже существует, его имя и IP используются без изменений.
